Clean native rewrite data recovery
Independent static decoding of supplied PRG, not REA output.
Exporter tools/extract_levels.py reads only original data tables; it does not execute
6502 code, decode instruction streams at runtime, or emit translated CPU statements.
Exported assets/levels/stage_01.json through stage_06.json and sprites.json.

Maps:
Stage banks 4,4,5,4,4,5. Fixed stage-indexed pointer arrays:
 CFF4 map sequence of page IDs (13 first five;14 final)
 D000 page records,128 bytes each (16 columns x8 metatiles)
 D00C metatile records,16 bytes each (4x4 tile IDs)
 D018 palette attributes indexed by original metatile ID
 CFEE common-metatile cutoff [0,17,0,17,17,0]
IDs below cutoff select stage0 definitions in bank4. Remaining IDs subtract cutoff
before indexing current stage definitions. Palette table uses unadjusted IDs.
The streaming routine CD7A increases source subrow4D/metatile-row4C/page4B while
subtracting destination nametable address by32. Therefore logical source tile rows
are reversed to produce top-to-bottom world image. Tile internal pixels not flipped.
Palette source subrows0/1 use attr high nibble, subrows2/3 low nibble; left half low
2bits of nibble, right half high2bits. This follows CF48 masks and is static-derived.
Map width512px, first5 heights3328, final3584. Preserve final sequence entry; it is
streamed into final boss viewport even when identical to preceding page.
Initial source row2 writes to nametable tile row29 (y232), yielding native camera
world_y=map_height-256-world_scroll. Need visual validation against reference capture.
Collision classes are computed from tile number and six stage thresholds at CFBE:
0 below a;1 [a,b);2 [b,c);0 [c,d);1 [d,e);2 [e,f);3 >=f.
Movement normally blocks nonzero classes. Stage index3 permits class3 but halves
velocity, per EA89..EAD7. Enemy/projectile terrain behavior still requires recovery.

Events:
F1E0 fixed pointers to bank6 stage tables:85F4,8941,9064,A151,AA5C,B128.
Each table has page pointers; script records are (pixel,xbyte,typebyte).
World event distance=page*240+pixel (distinct from map record height256).
X=(xbyte&127)*4; xbyte top bit spawns at bottom rather than top.
Type top bit invokes additional spawn selection at F1EC. It is retained as
conditional, not silently discarded. Odd trigger pixel requires difficulty3 in
F1A3..F1B1; retained odd_difficulty_only.
EF terminates page. F0 pixel begins forced scroll, F1 pixel prepares palette,
F2 pixel changes palette; retained separately as commands.
Unknown semantic kinds remain entity_XX. Do not present these as recovered distinct
behaviors until original routines are analyzed and their state transitions ported.
Entity type01..03 infantry share sprite12 routines. Boss type IDs09,20,25,40,17;
final gate49/core45/building4B. Some human-friendly boss labels are working labels,
not proof of exact original object composition. Spawn counts74,107,133,92,138,143.

Sprites:
Bank1 tables81F7 and8B5C each128 pointers map all256 sprite IDs. Frame records contain
count byte then count (signed dy,tile,attr,signed dx) tuples. 8x16 sprite dimensions.
Attrs low2bits palette,bit5 background priority,bit6 horizontal flip,bit7 vertical.
Hardware8x16 tile bank selected by tile lowbit, paired tiles begin tile&FE.
Per-object attributes are ORed and per-object flips XORed with part attributes;
object horizontal flip transforms dx=-dx-8, vertical dy=-dy-16.
Metasprite definitions recovered completely; animation timing/sequencing remains
part of original actor state logic and is NOT supplied by these frame records.

Native semantic asset refinement:
Raw handler/state candidates moved to analysis/native-entities.json. Runtime
entity_specs.json contains only named families, gameplay stats, frame IDs and semantic
parameters. Families assigned explicitly for all scripted source IDs; unresolved
visual identity within a family uses descriptive variant names. These category
assignments support a native authored behavior implementation; they do NOT establish
full recovery of every original state machine. Most entity handlers have5-9 states,
roughly30 independent families. Classifications vehicle/turret/environment for less
studied IDs remain provisional pending visual/reference validation.

IMPORTANT correction: event type highbit means priority allocation, NOT conditional
spawn. F1EC forcibly evicts an eligible entity if the16-slot pool is full. Flagged
variants can additionally alter handler logic. JSON retains raw_source_type and
priority_spawn. Odd pixel difficulty suppression remains a separate original check.
