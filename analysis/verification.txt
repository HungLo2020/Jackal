Native rewrite verification (2026-10-18)

The current default executable uses ordinary Rust systems, PNG/JSON maps and art,
and PCM WAV playback. Legacy generated/native_game.rs, assets/game-data.bin and
register-based game/video/audio runtime code have been removed from the working
tree. Optional reference exporters retrieve the old revision only into temp dirs.

Checks: cargo fmt; cargo clippy --all-targets -D warnings; cargo test; native
headless execution with PNG output. Detailed automated checks live in src module
tests, tests/native_regression.rs, tests/campaign.rs, tests/asset_validation.rs.
Reference fixtures: six start-screen captures and an 80-frame movement recording.
Background comparisons mask actors/HUD and require >=97% matching pixels.
Audio tests decode all 43 WAVs and validate loop lengths against the manifest.

Campaign tests intentionally set the camera near boss triggers and apply damage
to cover all six clears, ending and harder-loop restart. They do not demonstrate
a human completion, exact attack-pattern parity, or hardware audio accuracy.
Enemy and boss family behavior is authored. Original cinematics, some weapon and
rescue details, HUD and dynamic palette changes are not fully reproduced. README
and native-recovery.txt describe this fidelity boundary.

Historical verification of the previous translation is available in Git revision
e8fc3391d5b27fcd98b82fd27984141840449708; its 12 tests and PPM screenshots describe
that old implementation, not the current one.
